# LinkedIn Post — working draft

One post per assessment. 200–400 words. Public. Repository linked.

**The test:** would someone who does not know me learn something from this post?
If the only information in it is that I completed a task, rewrite it.

---

## Structure

**1. Open with the problem, or the thing that surprised me.**
Not "I just completed assessment two of my bootcamp."

**2. Name what I built. One sentence.**

**3. Teach ONE concept. Three or four sentences.**
The most interesting thing I learned, explained the way I would explain it to a
colleague. One concept. Not three.

**4. A real detail with a number or a specific behaviour in it.**
e.g. "bcrypt at cost 12 takes ~250ms per hash on my machine — barely noticeable
for one honest login, and brutal for an attacker testing millions."

**5. Link the repository.**

## Do not

- [ ] Write a progress update ("Week 6 done, learning so much")
- [ ] List technologies ("Built with Next.js, Prisma, PostgreSQL, TypeScript")
- [ ] Pretend it was easy
- [ ] Pretend it was harder than it was

## Check before posting

- [ ] Between 200 and 400 words
- [ ] Repository linked
- [ ] Teaches one concept properly
- [ ] Contains at least one specific number or behaviour
- [ ] A stranger learns something
